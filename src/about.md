# Hello!

This website contains slides and demos for a performance lecture about `requestAnimationFrame` that I ([Duncan Petrie](https://duncanpetrie.com "duncan’s website!")) gave at [Web Dev Conf](https://webdevconf.com/events/2026/ "WDC2026 - October 9 2026, Watershed, Bristol, UK | WDC") in October, 2026, and [London Web Standards](https://londonwebstandards.org/talks/bringing-spiders-to-the-web-with-requestanimationframe/ "Bringing Spiders to the Web with RequestAnimationFrame | London Web Standards") in November, 2026.

\
\
This is what the talk is (ostensibly) about:

> Animating on the web has never been easier. But what if you want to make life difficult for yourself?

> In this introduction to `requestAnimationFrame`, we’ll throw away the conveniences of modern life and learn how to build frame-based animations from the ground up. There will be cursor effects, spring physics, and, as if live demos aren’t scary enough, we’ll put an itsy-bitsy spider on the world wide web.

## spiders?

At the end of the talk, I show a website and browser extension that brings spiders to the world wide web. The website, [spiders.duncanpetrie.com](https://spiders.duncanpetrie.com "duncan’s web"), is a little playground where you can be a spider. The site is multiplayer, so **bring your friends**! If you get close enough together, you’ll start kissing (this is not a joke).

The [browser extension](https://chromewebstore.google.com/detail/a-spider-on-the-web/jnlhooedjlgccjkicbbolgbojlaigkle?authuser=0&hl=en "A Spider on the Web - Chrome Web Store") lets you take your spider on the go, to any website you visit. It can also periodically spawn spiders to run across your screen. This is a **fun addition** to the web browsing experience, and does **not** activate your fight-or-flight instincts.
